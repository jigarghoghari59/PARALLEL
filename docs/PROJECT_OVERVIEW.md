# PROJECT OVERVIEW — PARALLEL

**Tagline:** One Life. Infinite Possibilities.

## Vision
A portal to different versions of your life. Not a chatbot: an interactive hypothetical-reality exploration platform.

## Core Idea
One original decision -> multiple alternate realities -> different timelines -> infinite branches.

## Example
Input: "What if I had chosen Mechanical Engineering instead of Computer Engineering?"
- Reality 0 (original): Computer Engineering -> Software -> Tech industry
- Reality A: Mechanical -> Robotics -> Robotics Engineer
- Reality B: Mechanical -> Automotive -> EV Researcher
- Reality C: Mechanical -> Aerospace -> Space Researcher

Selecting an event (e.g., "Robotics Engineer in 2032") lets the user ask "What if I moved to Japan?" and generate a child branch connected to that event.

## Target User
Students and young professionals who like reflecting on life choices, creativity, and storytelling.

## Principles
- Fiction, not prediction.
- Working functionality over decoration.
- A connected journey: Dashboard -> Create -> Generate -> Explorer -> Timeline -> Branch -> Compare -> Save.

## Success Criteria
1. User enters a decision.
2. AI returns multiple distinct realities (valid JSON).
3. Timelines are visualized and nodes are interactive.
4. User can inspect events and branch from any event.
5. Universes can be saved and reopened.
6. Consistent premium dark visual identity.
